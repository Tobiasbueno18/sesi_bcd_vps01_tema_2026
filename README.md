# Tema 04 — Manutenção de Equipamentos

## Entregáveis
- `diagramas/MER_Conceitual.png` — modelo conceitual
- `diagramas/DER_Logico.png` — modelo lógico com PK/FK
- `Dicionario_de_Dados.md` — dicionário e normalização
- `csv/` — dados de teste separados por vírgula (mínimo 3 registros por tabela)
- `sql/ddl.sql` — criação do banco e tabelas
- `sql/dml.sql` — inserção dos dados de teste

## Como executar
1. Execute `sql/ddl.sql` no MySQL/MariaDB.
2. Execute `sql/dml.sql`.
3. Confira os dados com `SELECT * FROM nome_da_tabela;`.

Os CSVs correspondem aos registros do script DML.
